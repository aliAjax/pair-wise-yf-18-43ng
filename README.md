# hxyfront-62006 珠宝镶嵌宝石分拣

源提示词编号：8

我需要一个面向珠宝镶嵌工作室的宝石分拣前端系统，可以记录宝石编号、种类、形状、克拉重量、尺寸、净度、颜色、切工、镶嵌位置和分拣状态。页面需要有分拣批次、尺寸筛选、镶嵌位置示意图、缺陷备注和按订单查看的宝石清单。

## 订单配套锁定

分拣台已支持按订单配套锁定宝石套件：

- 每个订单从在库宝石中选择 1 颗主石与最多 8 颗围石；
- 主石净度至少 VS2；围石形状和颜色必须一致；整单总克拉不超过订单上限；
- 已属其他订单、缺检或缺陷未确认的宝石不能入套件（可在表内补检 / 确认缺陷）；
- 更换主石时先释放旧石并复核整套，复核失败自动保持原套件和原占用；
- 锁定、解锁、更换原因和订单清单均写入浏览器 localStorage，刷新后继续。

## 技术栈

React + Vite + TypeScript
