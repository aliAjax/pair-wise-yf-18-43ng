# hxyfront-62006 珠宝镶嵌宝石分拣 · 订单配套锁定

源提示词编号：8

面向珠宝镶嵌工作室的宝石分拣前端系统：记录宝石编号、种类、形状、克拉重量、尺寸、净度、颜色、切工、分拣批次与缺陷状态，并在分拣台上完成订单配套锁定。

## 配套规则

每个订单从在库宝石中选择 **1 颗主石 + 最多 8 颗围石**：

- 主石净度至少 **VS2**（净度证书未出视为缺检，不能入套件）；
- 围石的**形状、颜色必须全部一致**（不要求与主石一致）；
- 整套总克拉**不超过订单上限**；
- 宝石**已属其他订单、缺检（净度为空）、缺陷未获客户确认**时不能入套件；
- **更换主石**：先释放旧主石 → 放入新主石 → 复核整套；复核失败则保持原套件和原占用不变，旧石不会被释放；
- 锁定 / 解锁 / 更换主石都必须填写原因，结果与失败回滚情况写入操作记录；
- 订单清单、套件占用、锁定状态与全部原因记录保存在浏览器 localStorage，**刷新或重开页面后继续**。

## 页面构成

- 左侧订单清单：各订单主石 / 围石数量、克拉用量与锁定状态；
- 套件面板：镶嵌位置示意图（中心主石位 + 外圈 8 围石位）、实时复核结果与克拉用量条；
- 在库宝石表：形状筛选、只看可入套件、设为主石 / 加入围石，按钮按占用与规则禁用；
- 更换主石对话框：候选石预览 + 模拟“释放旧石→入位→复核”结果，必填原因；
- 操作记录表：锁定、解锁、更换主石的原因、结果与回滚留痕。

## 技术栈

React 19 + Vite 7 + TypeScript（纯前端，localStorage 持久化）
